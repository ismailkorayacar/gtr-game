# assets/sounds

Put real audio files here (`.mp3` or `.wav`, `.mp3` is tried first). Every file is optional; a missing file is skipped silently.

| file | use |
|---|---|
| engine_start | one-shot on first throttle press |
| engine_loop | seamless loop; pitch follows speed (playbackRate clamped 0.9–1.5) |
| tire_screech | loop, hard braking |
| tire_drift | loop, drift / handbrake / lateral slip |
| wheel_spin | loop, burnout / launch |
| nitro | loop while nitro is active |
| gear_shift | one-shot on each gear change |
| crash_car | one-shot, traffic collision |
| hit_barrier | one-shot, barrier hit |
| scrape_wall | loop, rubbing the barrier |
| traffic_horn | one-shot, traffic horn on close calls |
